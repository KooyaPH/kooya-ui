# @kooyaph/ui changelog

## 1.2.2

### Patch Changes

- Add a quiet utility presentation for workspace headers, avoid nested navigation landmarks, and keep long page actions within their containers.

## 1.2.1

### Patch Changes

- Simplify authentication and supporting information with focused AuthLayout and embedded consent, expandable descriptions, reusable RecordFields, resilient long labels and value-only loading across owned templates and controls. Preserve existing Ant APIs, themes and product-owned authentication behavior.

## 1.1.0

### Minor Changes

- 2b37580: Add controlled application authorization and value-level loading compositions. Preserve table headers and static template structure during pending reads; retain cached values during refresh. BusyBoundary callers should wrap custom dynamic fields in DataValue.

## 1.0.0

- Establish Editorial and Governance as the v1 workspace compositions. Default to Kooya Olive, Light and Compact, with twelve palettes and accessible custom accents.
- Add controlled appearance settings, adaptive workspace shells, and themed document-level popup hosts that escape clipped containers.
- Retain the catalogue and explicit legacy migration entry; retire the previous active layout comparison.

### Major Changes

- b5d364a: Replace the default public wrapper API with actual Ant Design controls and Kooya Signature branding. Add canonical component/type exports, native Ant-backed composition exports and synchronized appearance, density and feedback. Isolate prior wrapper contracts under /legacy. The standalone catalog adapts all public REUI recipes and includes functional groups, blocks, sections and page templates with a runnable source download.

## 0.3.0

### Minor Changes

- Release the source and distributable package under the MIT License.
- Add dedicated imports for Mosaic, Kooya Signature, Canvas, and Client themes.
- Allow bundled or consumer-defined `KooyaTheme` palettes in `KooyaProvider`.
- Keep named component exports available through each atomic family entry point.

### Patch Changes

- Make data table scroll areas keyboard-focusable and programmatically named.
