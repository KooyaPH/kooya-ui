# Security policy

Please do not report a security vulnerability in a public issue. Use GitHub's
private vulnerability reporting from the repository's Security tab. If private
reporting is unavailable, contact the KooyaPH maintainers through the
organization profile and ask for a private reporting channel.

Include the affected package version, a concise impact description, and safe
reproduction steps. Do not include real customer data or secrets. Maintainers
will coordinate a fix and disclosure with the reporter.
