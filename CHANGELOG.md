# Changelog

## 0.3.0 — first open-source release

- License original Kooya UI source and documentation under MIT.
- Add independently importable theme palettes and consumer-defined
  `KooyaTheme` objects.
- Keep all bundled themes in one provider catalog with separate public imports.
- Make component families available through atomic package subpaths.
- Establish public contribution, accessibility, setup, and release guides.

See [component documentation](docs/components.md),
[theme imports](docs/themes.md), and the repository
[release guide](docs/release.md).
