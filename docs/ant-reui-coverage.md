# Ant-first Kooya collection

The standalone catalog uses actual Ant Design 6.6.5 controls and Kooya's corporate palette, local wordmark, DM Sans Variable and Syncopate. The public root and `/components` retain Ant values, refs, props and compound APIs. This candidate does not migrate any product repository or publish a package.

## Actual source and engines

REUI public examples are preserved separately, byte for byte, at revision `3b67464bcad3c29fbdb12437afb70153384eee19` with its MIT license and SHA-256 manifest. The adapted files are generated from those originals; public examples and complete TypeScript supporting imports are retained in the runnable download. Code imports use local supporting paths; no upstream `@/` aliases are required.

The private recipe bridges use actual Ant controls for buttons, fields, selection, tabs, collapses, cards, avatars, badges, menus, overlays, feedback, tables, pagination, breadcrumbs, splitters, carousels, autocomplete, cascaders, steps, timelines, number fields and ratings. The source compositions remain recognizable while those engines use Kooya configuration.

Specialized REUI engines remain where their capabilities are needed: complex grids, event calendars, Gantt, drag and drop, emoji, code highlighting, questionnaire, signatures, date/phone/tree and other rich recipes. The catalog's dependency lists are computed from each actual runtime import graph; intake strategy labels describe intended adaptation, not proof that every rich engine is Ant. New advanced collections use Ant Design Charts, Ant Design X, React Flow, Tiptap and Excalidraw, with local fonts and sample assets.

## Composition coverage

Groups cover actions, inputs, labelled fields, choices, avatars, filters, row actions, navigation, metrics, status and cards. Blocks cover application shells, account flows, onboarding, dashboards, forms, profiles/settings, dialogs/drawers, lists/timelines/statistics/wizards, advanced planning/editing, data workflows, AI/operations and commerce. Sections cover all 18 planned marketing families. Templates retain and improve the original 17 families and add complete marketing, account, commerce, billing, scheduling, files, inventory, users, assistant, operations and catalog pages.

Interactions operate on fictional local state. Sorting/filtering/selection and CSV export share the same displayed records; export includes all matching pages in the selected order. Forms, uploads, events, boards, charts, editor content, cart/checkout and assistant history have local actions. No production API, payment, email, authentication or persistence is claimed.

## Verification and practical limits

Qualification uses package/playground/Storybook builds, workspace types, behavior tests, byte-preserved intake and resolvable source graph checks. Packed React18.3/19 consumers are separately checked with NodeNext TypeScript, SSR and native Ant identity. The downloadable standalone project is installed and built independently.

Browser mount sweeps check every registered variant for load failures and uncaught errors; these are distinct from the focused interaction checks. Review also covers narrow layouts, keyboard navigation, focus return, appearance propagation into isolated previews/portals, reduced motion and larger text. A mount sweep does not prove every possible interaction in 1241 upstream recipes.

Large advanced-engine and syntax chunks trigger Vite bundle-size advisories. Heavy engines and examples load lazily. Some inherited upstream/demo warnings remain; the preview is a local library candidate, not a production performance or full WCAG certification.
